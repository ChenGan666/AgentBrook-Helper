本次更新重点：Token卡计费体系全面上线（购买/充值/体验卡）+ 模型配置与交互体验大幅增强。

【Token卡 · 计费与购买】
- 全新 Token卡计费体系：不记名预付费卡（鉴权 Key + 面值余额），支持微信 Native 扫码支付
- 购买页支持面值快捷选择与自定义金额；支付成功自动发卡/充值并自动跳转展示，Key 一次性展示防丢失
- 体验卡：引导窗「获取体验卡」按钮手动申请（5 元 / 24 小时），绑定设备与网络；支持 IP 白名单（精确 IP / CIDR）与每 IP 限量，开放开关可控
- 发卡页新增「自动回填到 Helper」：一键把 Key 写入 Helper 模型配置并拉起设置窗，全程免粘贴
- 余额与消费流水随时可查（凭 Key）；后台支持订单管理、人工确认与微信退款
- 站点首页底部展示 ICP 备案号（链接工信部备案系统）

【模型设置 · 能力增强】
- 「获取模型列表」：凭 API Key 自动拉取模型清单与参数（上下文窗口/最大输出），不再需要手动输入模型名
- AgentBrook / DeepSeek 供应商支持余额自动查询与显示
- 多 Key 模型支持：同一供应商可配置多个模型，切换更灵活
- 占位符 Key 智能检测：配置为占位符时给出明确提示，默认供应商配置自动保障
- 会话交互卡片统一重构：授权/确认/选择/答复/执行结果折叠展示，头部状态一目了然，长内容限高可展开

【其他】
- Skill 支持启用/禁用（禁用的技能不加载不注册）
- 会话标题过长自动省略号截断，不再遮挡操作按钮；排队消息支持一键删除；引导窗内容可滚动
- 模型设置三列布局固定，长内容独立滚动
- 界面多语言（中文/English/Bahasa Indonesia）覆盖全部新增功能
- 稳定性修复：伙伴上下线判定更快更准（退出即离线、离线不再"复活"）、模型列表自动刷新改为气泡提示
