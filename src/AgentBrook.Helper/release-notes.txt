本次更新重点：任务产物（Artifacts）独立展示区——交付文件一目了然可点击打开；失败一键重试；隐私脱敏插件持续完善；全新头像系统。

【任务产物（新功能）】
- 任务产生文件时，助手最终回复底部出现「任务产物」卡片：任务工作目录 + 最终交付文件清单，点击直达
- 交付文件由模型调用 register_artifact 登记（含一句话用途说明）；媒体生成的远程链接自动登记
- 产物随会话持久化：历史会话回放同样还原产物展示区；回合中途出错，已产出部分也会保留展示
- 交付文件统一放任务目录 tasks/<时间-任务名>/deliverables/，与中间产物隔离，工作区更整洁

【失败一键重试】
- 任务执行失败（网络中断、服务端超时/过载等）时，错误提示下方直接提供「重试」按钮，点击复用原消息重发
- 余额不足/卡失效的提示：充值入口与重试并排，充值完成后一键重新执行

【头像系统（新功能）】
- 设置 → 通用：为你的 Helper 挑选头像，emoji 或自定义图片
- 内置头像制作器：选择本地图片 → 拖动定位 + 缩放框定裁切区 → 一键导出应用
- 局域网协作场景：对方 Helper 的自定义头像同步展示，消息来源一眼可辨

【隐私脱敏（插件形式提供，本轮持续完善）】
- 设置 → 插件管理：一键安装「隐私脱敏」插件，随系统启动自动加载，支持热插拔（启停/重装即时生效）
- 出站遮蔽：手机号、邮箱、身份证、银行卡、车牌、IP、网址、护照等 11 类内置规则自动识别，带校验位复算
- 智能识别（NER，可选）：按需下载本地识别模型（约 97MB，离线推理），识别词典外的人名等实体，置信度阈值可调
- 回复自动还原：模型回复中的脱敏标记在展示前完整还原为真实值；流式过程中短暂显示标记属正常
- 脱敏徽标：每条回复旁显示插件图标 +「已脱敏 N 处」，悬停可查看模型实际收到的文本（可复制）
- 识别类别可逐类开关；失败模式可选（默认脱敏失败即中止发送，绝不让原文出门）

【敏感词典与白名单】
- 词典三标签页：基础设置 / 敏感词词典 / 白名单，多语言齐全
- 词典支持任意自定义类别（如 KEY、SECRET）：添加 / 搜索 / 类别过滤 / 启停 / 别名 / 删除
- CSV 批量导入导出；白名单豁免规则让特定内容原样通过
- 人名等实体建议加入词典获得固定编号（跨会话稳定还原）；NER 临时识别不进词典（防误报固化）

【插件系统（新基础设施）】
- 插件标准化：按需下载、签名校验、热插拔、统一下载通道、设置页声明式标准
- 插件列表 / 安装 / 卸载 / 启停 / 独立设置对话框（多语言）
- 气泡上半圈实时显示调用中的插件图标：悬停放大、点击直达插件设置、展示最少 3 秒

【修复与优化】
- 工作区自动清扫浏览器自动化遗留的临时目录（.chrome-* / .playwright-* 等），不再长期占用磁盘
- 多附件输入条自动换行排列，附件较多时不再挤出可视区
- 更新检查改为三时点制（09:30/13:30/21:30）精确等待，长期不关机每 6 小时补查，等待期零唤醒
- 更新提醒气泡内容过长时显示滚动条，不再截断
- 顶栏会话切换器弹性布局：长标题随宽度自适应省略

【上一版 1.0.149 回顾】
- 会话阶段稳健性：阶段分类/摘要改走会话主模型；阶段轨随启动回放重建
