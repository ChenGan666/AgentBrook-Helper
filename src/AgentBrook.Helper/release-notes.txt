1.0.168 新增：IM 语音识别——Telegram / 微信收到的语音消息自动转写成文字后交给助手处理（会话与回复显示「[语音] …」）；提供「本地离线识别插件」（插件市场安装，模型从服务器下载，音频不出本机）与「云端转写模型」（模型设置里独立选择）两种方式。同时修复插件管理：手动删除插件目录后可用插件列表不显示、微信插件卸载后仍显示已启用等。

【IM 语音识别（新功能）】
- Telegram / 微信语音消息自动转写为文字进入对话；转写结果随消息持久化——重启不重复转写、回合重试不重复调用
- 微信语音优先采用平台自带转写文本（无需额外识别）；平台未给文本时回一条明确提示
- 会话投影显示「[语音] 转写内容」，与 IM 回复、主窗口显示一致
- 未配置识别能力 / 转写失败 / 音频无法获取：给出明确回音，不影响同条消息的其他内容

【本地语音识别插件（新功能 · 离线）】
- 插件市场新增「本地语音识别」：sherpa-onnx + SenseVoice 模型，支持中/英/日/韩/粤，全程本机推理，音频不上传
- 模型（约 228MB）从服务器插件目录下载并做 SHA-256 校验；设置页可安装、自检、内置样例测试、删除模型
- 停用 / 卸载即释放推理内存；模型存放在工作区共享目录，插件升级或重装无需重新下载

【模型设置】
- 模型页新增「转写模型」：指定某供应商的模型专用于语音转写（与对话模型相互独立，可手填模型名；非 OpenAI 兼容供应商会被拦截提示）
- 多媒体下拉只列图像 / 视频模型；对话模型下拉不再显示已被选为转写模型的条目

【插件与更新修复】
- 手动删除插件目录后，「可用插件」不再将其误判为已安装（启动 / 刷新时自动清理残留状态）
- 微信插件卸载后 IM 面板不再显示「已启用」；卸载 IM 通道插件会同步关闭对应通道开关（配置保留，重装后需手动开启）
- 隐私脱敏插件的内置推理库升级，与本地语音识别插件并行加载不再冲突
- 插件市场索引改为按实际安装包重算校验值，修复偶发「插件包 SHA-256 校验失败」

1.0.167 修复：开启隐私脱敏插件时，IM 回复以及授权/提问提示里的脱敏占位符（如 [人名1]、[电话1]）现在会先还原为真实内容再发送，与主窗口显示一致；会话投影同样落还原后文本。

1.0.166 修复：IM 多轮对话偶发「会话保存失败：[RevisionConflict] 陈旧快照」——表现为模型反复重跑、同一条回复重复出现/重复提问。根因：上一回合由提交协议推进 CURRENT，进程内载入基线未刷新（同一会话切换被短路）。现在每个 IM 回合开始强制从 CURRENT 重载对齐版本；失败回合丢弃未提交内存态；同一条消息连续失败 5 次停止自动重试并回一条失败提示。

1.0.165 新增：IM 对话确认——工具授权与 ask_user 提问改在 IM 聊天里完成（1=允许 / 2=拒绝；提问可回数字选项或直接输入回答），不再弹电脑上的授权/提问卡；超时默认拒绝、非配对者回复无效、审批期间发来的其他内容按"拒绝当前操作 + 作为新消息继续处理"。设置 → IM 连接新增「IM 授权方式」：对话确认（默认）/ 自动放行（旧行为，兼容开关）。

1.0.164 修复：安装版扫码登录微信成功后「保存失败：ExecuteNonQuery can only be called when the connection is open」——独立登录宿主的数据库被提前释放，现保持到进程退出（同一通道下次登录时替换旧连接）；微信图标改为绿色（#07C160）；「打开诊断日志」在日志目录尚未生成时自动创建并打开，不再无反应；host-log.txt 新增清理策略——只保留最近 200 条，且文件不超过 128KB。修复 IM 回合在主窗口会话里重复显示回复（微信侧只发一份）：多轮工具调用回合的转写按轮落盘，并自动清理旧版本已产生的相邻重复行。启动期失败的终端诊断（如 MCP 服务器连接失败）改为静态失败卡：不再显示「执行中」流光与计时器，直接定格为「失败」。

本次更新重点：微信通道（新功能）——手机微信直接和你的 Helper 对话，文本、图片、文件双向互通，工具能力与主界面一致。

【微信通道（新功能 · iLink 官方通道）】
- 设置 → IM 连接 → 微信卡片 →「扫码登录微信」：手机扫码（如提示则输入数字配对码）→ 自动保存并启用，无需公网 IP、无需隧道、无需部署任何桥
- 基于腾讯 2026 年开放的 iLink（ClawBot）个人微信 Bot 通道，桌面端长轮询接收消息；登录约 24 小时有效，失效时卡片会明确提示重新扫码
- 换号自动对齐：重新扫码后 bot 账号变化时，自动把配对关系与会话映射迁移到新账号，不会丢会话、不需要重新配对
- 与 Telegram 通道能力一致：同权执行（多轮工具、终端命令、文件读写、生成媒体）、执行过程在主窗口实时可见、只把最终结果回给对方

【微信媒体双向（新功能）】
- 收：手机发来的图片自动下载解密并进入会话（模型按当前所选模型能力解析内容）；语音优先取平台转写文本，文件/视频同样接收存档
- 发：Helper 生成或截取的图片、文件、视频会加密封装后发回微信（图片走图片消息、其他走文件消息），不再只回文字
- 中文说明：媒体与文字按平台规范分开投递；文件大小上限 50MB/条

【IM 通用改进】
- 「重新绑定通道」按钮：设置页可直接重试通道绑定，无需重启；批量重绑幂等，不会产生重复通道
- 「打开诊断日志」按钮：IM 运行日志（含通道收发与回合执行）落盘到 工作区/im/host-log.txt，一键打开查看
- 通道状态可见：异常时在 IM 板块直接显示原因（如登录失效、轮询失败），无需翻日志
- 卸载/重装更可靠：插件卸载会先释放程序集再删除目录，占用时自动改名待清理；安装偶发的校验误报已修复（重试 + 稳定哈希读取）
- 停止/重绑不再丢消息：已拉取到的一批消息会完整处理后再退出，避免"日志显示收到但无反应"
